## 暫定の実装判断（製品仕様の確定ではない）

- SwiftUI・ObservableObjectによる状態管理。保存先はRepositoryで分離。
- iOS 17.0以降。JPYの整数円（1〜999,999,999,999円）。
- 実データなしで個人用・共有用の2冊と標準未分類・お財布を生成。
- 未確定のカテゴリ基本セットは作らず、未分類のみ。利用者が追加できる。
- タグ表示の初期値はON。タグ未選択の履歴検索は全件。文字検索はメモ・カテゴリ名。
- アーカイブ済みカテゴリ・口座・タグは、既存取引で保持しているもののみ編集時に保持可。
- 一般入出金元の同名は許可（制約は未決定）。
- Bundle Identifierは仮の `com.mikwk.budgetbook`。配布用Team・署名は未設定。
