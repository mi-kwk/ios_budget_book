# iPhone家計簿アプリ

Notionの確定仕様に基づく、開発中の家計簿アプリです。カテゴリの名称変更・所属変更・並べ替え・階層選択に対応しています。完成版ではありません。

## 開き方

Finderの「書類」→ `ios_budget_book` → `BudgetBook.xcodeproj` をダブルクリックします。
Xcodeで `BudgetBook` スキームとiPhoneシミュレータを選び、▶︎（Command + R）で実行します。
実機の場合は Signing & Capabilities で自分のTeamと固有のBundle Identifierを設定してください。

## 必要環境

- Xcode 26.3（今回ビルド確認した環境）
- iOS 17.0以降（仮の最低対応。製品仕様としては未確定）
- SwiftUI / Charts / Foundation。追加パッケージ・銀行API・広告SDKなし

## 構成

- `BudgetBook/App`：アプリ起動・状態管理・保存処理との接続
- `BudgetBook/Domain`：家計簿・取引・カテゴリ・タグ・入出金元、入力制約、集計
- `BudgetBook/Data`：Repositoryと暫定の端末内JSON保存
- `BudgetBook/Features`：ホーム・入出金・収支・入力・設定
- `Tests`：集計・入力制約の実行テスト
- `docs/implementation-status.md`：仕様との対応・仮決定・未実装項目

## 検証

```bash
bash Scripts/test-domain.sh
xcodebuild -project BudgetBook.xcodeproj -scheme BudgetBook -sdk iphonesimulator CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- build
```

ローカル保存はApplication Support内の `BudgetBook/budget-v1.json` です。保存エラー時はUIの状態を確定せず、読込エラー時は空データで上書きせず編集を停止します。
端末内保存ファイルと暗号化バックアップファイルは別です。設定からパスワード付きファイルの書き出し・復元ができます。iCloudの手動／自動バックアップも実装しています。接続には開発用のCloudKit設定が必要です。

変更履歴はGitで管理し、GitHubの `mi-kwk/ios_budget_book` と連携します。

## カテゴリの管理

設定（歯車）→カテゴリから大カテゴリを開き、名称変更と小カテゴリの編集・所属変更ができます。「編集」から同じ階層内の順序を変更できます。
取引入力ではカテゴリを押し、大カテゴリ→小カテゴリの順に選択します。未選択で保存すると「未分類 ＞ 未分類」になります。大カテゴリだけでは登録できません。

初回起動では「個人用」1冊を作成し、新規家計簿にはNotionで確定した初期カテゴリセットを作成します。すでにある家計簿は「基本セットを確認・追加」で必要な項目を追加してください。既存の取引・カテゴリは自動で書き換えません。

## タグ・入出金元の管理

設定→タグ／入出金元で項目を開くと、名称変更やアーカイブ・復元ができます。入出金元の順番は「編集」から変更します。標準お財布は名前変更・アーカイブできません。

タグを追加する際、同名のアーカイブ済みタグがあれば復元して再利用できます。名称変更によって過去取引との関連は切れません。
取引入力の出金元・入金先を押すと選択画面が開き、右上＋から追加できます。追加後は一覧から選択してください。

## バックアップ・復元

設定 → バックアップ・復元で、8文字以上のパスワードを使って `.budgetbackup` を書き出せます。復元時はファイルの日時・件数を確認してから全データを置き換えます。復元前の状態は端末内に暗号化して7日間保持し、戻す・早期削除ができます。

詳細な操作、形式・保存方式は `docs/backup-design.md` を参照してください。ファイルは32MBまで対応。iCloudの接続設定・動作条件は `docs/icloud-setup.md` を参照してください。

復元前退避の鍵にはKeychainを使います。シミュレータでも署名を無効にせず、Xcodeの通常実行か上記のアドホック署名付きビルドで確認してください。署名なしでは鍵取得に失敗し、復元を中止する場合があります。


## 返金

支出の詳細で「この支出の返金を登録」を選ぶと、部分返金・複数回返金を記録できます。元支出の金額を超える返金は保存できません。返金は返金日の支出から差し引きます。元支出のカテゴリ・集計対象は返金にも連動し、タグは返金ごとに変更できます。

新しい取引の上限は999,999,999円、お店・相手先は100文字、メモは1,000文字です。保存済みの種類は変更できません。元支出を削除すると関連返金も削除します。


カテゴリの保存構造を更新しました。標準未分類は収支別の親子セットで保護します。旧版の大カテゴリに直接紐づく取引は、同じ親の「直接登録（移行分）」という小カテゴリへ移行します。既存の取引ID・金額・返金関連を保持し、既存のカテゴリ名・順序を自動変更しません。移行後は旧版アプリへのダウングレードに対応しません。
