## 暫定の実装判断（製品仕様の確定ではない）

- SwiftUI・ObservableObjectによる状態管理。保存先はRepositoryで分離。
- iOS 17.0以降。JPYの整数円（1〜999,999,999,999円）。
- 実データなしで個人用・共有用の2冊と標準未分類・お財布を生成。
- 基本カテゴリはユーザー了承により一般的なセットを仮採用。新規家計簿は自動作成、既存家計簿は設定から一覧確認後に追加。
- タグ表示の初期値はON。タグ未選択の履歴検索は全件。文字検索はメモ・カテゴリ名。
- アーカイブ済みカテゴリ・口座・タグは、既存取引で保持しているもののみ編集時に保持可。
- 一般入出金元の同名は許可（制約は未決定）。
- Bundle Identifierは仮の `com.mikwk.budgetbook`。配布用Team・署名は未設定。

## カテゴリ管理の追加実装（2026-11-08）

- 大・小カテゴリの名称変更、小カテゴリの所属先変更を実装。同じ家計簿・収支種別の大カテゴリ間で移動し、ID・過去取引金額は保持する。通常集計は現在のカテゴリ階層を参照する。
- 名称の空白除去、使用中・アーカイブ済みを含む同一階層の重複禁止、三階層化・自己参照・家計簿越境を防止。
- 大カテゴリおよび同じ親配下の小カテゴリを「編集」モードでドラッグして並べ替え。JSON再読込後も順序を保持。旧データのorderが同じ場合は元の配列順を保持する。
- 取引登録のカテゴリ選択を大→小の専用画面へ変更。各選択画面の右上＋で追加でき、大カテゴリ自体でも登録可能。
- 親アーカイブ・復元は子自身のアーカイブフラグを変更しない。過去取引編集でアーカイブ済みの現在のカテゴリを保持する導線を用意。
- ユーザーに一般的な基本セットの仮採用を確認済み。支出は食費・日用品・交通費・住居費・水道光熱費・通信費・医療健康・趣味娯楽・その他、収入は給与・その他を用意し、小カテゴリを設定。
- 新規家計簿には基本セットを自動作成。既存家計簿には自動追加せず、設定の「基本セットを確認・追加」から追加する。同名は再作成せず、アーカイブ済みの親は配下ごとスキップ。
- 追加で、カテゴリ選択から戻った際に入出金元の入力値を初期化しないよう修正。
