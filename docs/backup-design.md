# 暗号化バックアップ・復元

## 利用方法

設定 → バックアップ・復元を開きます。

1. 書き出し用パスワードを8文字以上で2回入力し、「ファイルへ書き出す」を押します。
2. iOS標準の保存画面で保存先を選びます。拡張子は `.budgetbackup` です。
3. 復元するときはパスワードを入力してファイルを選択します。
4. 復号・検証が成功するとバックアップ日時、家計簿数、取引件数が表示されます。ここではまだ置き換えません。
5. 確認後に「全データを置き換えて復元」を選ぶと、現在の全家計簿・設定を置き換えます。
6. 復元前に戻す場合は、保持期限内に「復元前に戻す」を選びます。復元後の追加・編集は失われるため、必要なら先に書き出してください。

パスワードはアプリで保存しません。忘れた場合の復旧手段はありません。現在の実装はファイル上限32MBです。保存先は利用者が選び、アプリの書類フォルダの公開設定は行いません。

## ファイル形式 v1

- UTF-8 JSONの外側に形式名、ファイル版、アルゴリズム、salt、反復数、暗号文を保持。
- パスワード鍵導出はPBKDF2-HMAC-SHA256、600,000回、16バイトのランダムsalt、256ビット鍵（CommonCrypto）。
- 本文はAES-256-GCM（CryptoKit）。nonceは毎回生成し、形式・版・アルゴリズム・反復数・saltを追加認証データとして結び付ける。
- 本文にBackupPayload版、作成日時、BudgetSnapshot全体を保存。日時・件数・メモを外側に平文で出さない。
- 対応しない版・アルゴリズム・反復数、過大ファイルは重い処理より先に拒否。
- パスワード違い・破損・改ざんは復号できず、現行データを変更しない。
- 全家計簿、取引、カテゴリ、タグ、入出金元、それらの関連・アーカイブ、保存済みの表示設定・選択家計簿を対象とする。復元前の退避は端末専用であり、ポータブルファイルへ再帰的に含めない。

## 復元・退避の原子性

`budget-v1.json` は `BudgetStorage(storageVersion: 1, snapshot, rollback)` として保存する。旧形式のSnapshot単体JSONも読み、次の保存時に移行する。

1. 復号後に全IDの一意性、家計簿所属、カテゴリ階層、標準未分類・お財布、金額・参照・表示設定を検証。
2. 現行Snapshotを読み、端末専用鍵でAES-GCM暗号化したRollbackRecordを作成。
3. 復元先SnapshotとRollbackRecordを同じファイルへ `.atomic` / `.completeFileProtection` で書き込む。
4. この保存に成功してからメモリ上の表示状態を確定する。書込失敗時は現行ファイルと以前の退避を維持する。

退避は最新1件、復元から7×24時間保持する。通常の編集で期限は延長しない。起動時・アプリのアクティブ化時・バックアップ画面表示時に期限切れの退避だけを削除する。失敗時はエラーを通知し、現行データは維持する。手動の早期削除にも対応。

退避鍵はKeychainの `WhenUnlockedThisDeviceOnly` に保存し、iCloud同期しない。鍵が取得できないときは復元や戻し処理を中止する。保存済みの退避を開く際に別の鍵を新規生成しない。

- App Store配布時の暗号化に関する申告。

## カテゴリ構造の移行

SnapshotはschemaVersion 2へ更新。外側の暗号化形式・BackupPayload版は1を維持する。旧版1のSnapshotは旧制約で検証し、未分類親子と通常カテゴリの移行用の子へ取引を割り当てて版2へ移行する。旧ファイルからの復元・旧退避への戻しでも適用する。詳細と維持する項目は `implementation-status.md` のカテゴリ移行の節を参照。新版データの旧アプリでの読込は非対応。
