- 大カテゴリおよび同じ親配下の小カテゴリを「編集」モードでドラッグして並べ替え。JSON再読込後も順序を保持。旧データのorderが同じ場合は元の配列順を保持する。

- 親アーカイブ・復元は子自身のアーカイブフラグを変更しない。過去取引編集でアーカイブ済みの現在のカテゴリを保持する導線を用意。
- ユーザーに一般的な基本セットの仮採用を確認済み。支出は食費・日用品・交通費・住居費・水道光熱費・通信費・医療健康・趣味娯楽・その他、収入は給与・その他を用意し、小カテゴリを設定。

## タグ・入出金元の追加実装（2026-11-08）

- 設定のタグ一覧から名称変更・アーカイブ・復元を実装。ID・過去取引との関連・タグ表示設定を保持する。別家計簿の同名は許可し、同一家計簿の使用中／アーカイブ済みを通した重複を禁止。
- 新規作成時に同名のアーカイブ済みタグがある場合、保存の代わりに「既存タグを復元して使用する」を表示。新しいタグIDは作らない。名称変更先に同名の別タグがある場合は自動統合せずエラーにする。
- 入出金元の名称変更・アーカイブ・復元・並べ替えを実装。過去取引の参照IDと金額を保持する。
- 標準お財布は専用フラグで判定し、名前変更・アーカイブをデータ層で禁止。物理削除の操作は提供しない。表示順の変更は可能。
- 取引入力の入出金元を専用の選択画面へ変更。右上＋から追加し、追加後は一覧から選択する暫定動作。収入・支出の選択候補に「未指定」は設けず、振替のみ指定できる。
- アーカイブ済み入出金元は新規候補から除外。過去取引の編集では元の入出金元を保持できる。
- 入出金元のorderはOptionalで追加。既存JSONのorderなしデータは配列順を維持し、新規追加は末尾。保存形式のバージョン変更は不要。
- タグ名の正規化は従来どおり前後空白の除去のみ。一般入出金元の同名は従来どおり許可（どちらも未決定事項として維持）。

## 暗号化ファイルのバックアップ・復元（2026-11-08）

- パスワード確認、標準ファイル書き出し／選択、`.budgetbackup` 型登録を追加。
- PBKDF2-SHA256（600,000回、ランダムsalt）＋AES-256-GCMで日時・全Snapshotを暗号化。パスワードは保存しない。書き出しは8文字以上、ファイル上限32MB。
- 復号・整合性検証後に日時・家計簿数・取引件数と全置換の注意を表示し、確認後のみ復元。
- 復元前データは端末専用Keychain鍵で暗号化して最新1件を7日間保持。復元先と退避を同じファイルへ原子的に保存し、失敗時は元ファイル・以前の退避を維持。
- 起動・アクティブ化・画面表示時に期限切れ退避を削除。手動削除と、警告・書き出し案内後の「復元前に戻す」に対応。
- 旧Snapshot単体形式を読み、通常保存時に新コンテナへ移行。ポータブルファイルへ端末専用の退避データは含めない。
- 暗号化ファイルの詳細は `docs/backup-design.md`。iCloud追加実装は後述。
- 書類フォルダを公開する追加設定は、自動承認レビューでデータ公開範囲拡大の可能性を理由に拒否されたため未採用。標準の保存先選択で保存・読込できることを確認済み。

## iCloudバックアップの追加実装（2026-11-08）

- CloudKit private databaseへ暗号化した全データを手動保存。アプリ使用中は変更がある場合に1日1回、自動保存する。失敗後15分は自動再試行を控える。常時同期・バックグラウンド定時実行は行わない。
- 保存成功を確認してから3世代に整理。アップロード失敗時は既存世代を削除せず、整理失敗時は多めに残して警告する。
- 一覧→パスワード復号→日時・家計簿数・取引件数の確認→全置換に対応。既存の7日間の復元前退避と戻す処理を利用する。
- iCloud用パスワードはアカウントごとに端末専用Keychainへ保存し、自動保存に利用。他端末には同期せず、移行時は同じパスワードを入力する。復元・戻す直後は自動保存を一時停止する。
- アカウント変更を検知したら自動保存を停止。通信・容量・署名設定エラーを表示し、端末内データを保持する。
- CloudKit設定は既定で無効。未設定でも起動・端末内保存・ファイルバックアップを利用できる。設定手順とentitlements例を追加。
